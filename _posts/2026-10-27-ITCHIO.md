# We Made a Mini Project for itch.io!

Hey! In an effort to test out some unfamiliar territory (most namely procedural generation), we made a little game based on a favorite of mine!
If you have ever heard of Stratego, or are a big fan of Strategy games like Chess, then you will notice a familiar play style. That is because it is based on those games!
We picked a relatively basic rule set so that we could focus on things like procedural generation and choices made by game AI. 

I was recently inspired by Alien: Isolation's Director AI and how it manages to control the pace of the game and play. And I have been curious about using seeded procedural generation to randomize object placement.
We haven't been able to do anything as genius as Alien: Isolation quite yet but we were able to get a basic AI going that you play against. Its certainly no better than, say a villager from Minecraft, but it is a start!
